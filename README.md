# Projeto de Teste – Git & GitHub

Repositório criado para praticar comandos básicos do Git e fluxo com GitHub.

## 📚 O que pratiquei
- `git status`
- `git branch`
- `git log`
- `git log -p`
- `git log --oneline`
- `git remote`
- `git revert`
- `git reset`
- `git add / commit / push / pull`

## 🔄 Fluxo básico
```bash
git add .
git commit -m "mensagem"
git push
```

## 🌿 Branch
```bash
git checkout -b minha-branch
git push -u origin minha-branch
```

## ⏪ Desfazer alterações
```bash
git revert <commit>
git reset --hard <commit>
```
